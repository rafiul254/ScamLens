# ScamLens URL dataset card

Generated by `ml/build_url_dataset.py` on 2026-10-16 20:09 UTC (seed 20261017).

* **Source:** PhiUSIIL Phishing URL Dataset (Prasad & Chandra, 2024), UCI ML Repository #967, CC BY 4.0.
* **Size used:** 60000 URLs sampled class-balanced (30000 phishing, 30000 legitimate) from the full 235,795-row corpus, plus 6435 curated local URLs (3580 look-alikes, 2855 official-domain pages) added to the training split only — derived from the brand list in `backend/app/services/url_analyzer.py`.
* **Features:** the 27 lexical features computed by `backend/app/services/url_analyzer.py` — the same code path used in production, so no train/serve skew.
* **Splits:** 70% train / 15% validation / 15% test, shuffled with seed 20261017.

## Limitations

* PhiUSIIL URLs were collected in 2023–2024; brand-impersonation patterns for South Asian mobile-money brands (bKash, Nagad, Easypaisa) are covered by our curated brand list rather than by this corpus.
* The dataset's legitimate class skews to established English-language sites, so the model can be over-confident on legitimate small local sites — the rule layer (brand whitelist, TLD list) compensates.
* Lead-out guarantee: the URLs in `ml/url_sanity_set.py` are excluded from the curated slice, so that sanity check stays a held-out measurement.
* The curated local slice was added after a measured failure: with PhiUSIIL alone the model scored `https://www.bkash.com/terms` at 0.99 (false alarm) and that URL is now in the training split. The held-out test split is deliberately left as pure PhiUSIIL, so the published metrics do not benefit from the local slice and remain comparable across runs.
* We never fetch or render the URL during training or inference; only the optional HEAD redirect probe touches the network at request time.
